RetailHub | Typescript, Next.js, React, Node.js, MongoDB, REST API
Sistema web full-stack pensado para reduzir erros no controlo manual de inventário, evitar rupturas ou excesso de
stock e dar ao gestor uma visão rápida do desempenho de vendas sem depender de folhas ou de várias ferramentas
desligadas entre si. Resolve o problema da informação dispersa: centraliza produtos (preço e stock num só sítio), registo
de vendas, alertas quando o stock está baixo e dashboard com resumo e gráfico dos últimos 7 dias.
Funcionalidades: autenticação de utilizadores; dashboard com métricas e gráfico; inventário com CRUD completo de
produtos (criar, editar, apagar); registo de vendas que atualiza automaticamente o stock e os totais diários na base de
dados; alertas de stock baixo.
